# Русский Ясно v22 — персональный адаптивный маршрут

- Банк независимых экзаменационных заданий передаёт тематическую метку в журнал ошибок.
- На странице прогресса добавлен ориентировочный индикатор готовности по каждому маршруту.
- Индикатор учитывает долю освоенных разделов и средний результат до трёх последних экзаменов; без попыток учитывается освоение тем.
- Добавлены персональные рекомендации на основе сохранённых ошибок с быстрым запуском тематической тренировки.
- В разделе «Мои ошибки» появилась кнопка запуска повторения по наиболее частой/свежей ошибке.
- Варианты и порядок ответов перемешиваются.

Индикатор — внутренний учебный ориентир, не прогноз официальной оценки и не гарантия сдачи. Старые записи ошибок сохраняются; если в них вместо темы сохранено название задания, система не угадывает и не подменяет тему автоматически.
