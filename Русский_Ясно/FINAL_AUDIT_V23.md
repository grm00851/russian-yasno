# Финальный аудит Русский Ясно v23

## Изменения
- Service Worker обновлён до v11.
- При установке кешируются HTML-оболочка и локальные JS/CSS-ресурсы, обнаруженные в HTML.
- Посещённые same-origin ресурсы кешируются при успешной загрузке; при потере сети навигация возвращает кешированную оболочку приложения.
- Обновлены PWA-иконки, manifest и apple-touch-icon.
- В настройках появился индикатор сети.
- Добавлен экспорт прогресса в JSON и импорт резервной копии на другом устройстве.
- Импорт проверяет имя приложения, версию формата, структуру основных данных и размер файла (до 5 МБ), затем запрашивает подтверждение замены текущего прогресса.
- Добавлены инструкции установки для iPhone, Android, Chrome и Edge.
- Улучшен вид клавиатурного фокуса для textarea и select.

## Проверки, выполненные в этой среде
- Архив v22 распакован без ошибок.
- TypeScript/TSX синтаксис проверен транспиляцией TypeScript: 4 файла, синтаксических ошибок нет.
- JavaScript syntax: eslint.config.js, public/sw.js и scripts/generate-pwa-icons.mjs прошли `node --check`.
- CSS: количество открывающих и закрывающих фигурных скобок совпадает.
- Учебная программа: 100 уроков (20 базовых, 40 ОГЭ, 40 ЕГЭ); нет повторяющихся ID и пустых обязательных полей; у всех уроков есть валидные варианты ответа.
- Банк независимых экзаменационных заданий: 75 заданий; нет пустых обязательных полей и дубликатов; все 25 тематических меток совпадают с темами учебной программы, по 3 задания на тему.
- Service Worker проверен `node --check`.
- Итоговый ZIP проверен тестом целостности.

## Что не удалось подтвердить
- Полный `npm ci` не завершился в доступное время среды; полноценные `npm run lint` и `npm run build` не выполнены. Глобальная проверка TypeScript ограничилась синтаксической транспиляцией и не заменяет полную типовую проверку проекта.
- Не проводились реальные браузерные E2E-тесты на физических iPhone, Android и компьютерах.
- Офлайн-работа реализована через PWA-кеширование, но фактическое поведение зависит от браузера, HTTPS, успешной первой загрузки и того, что браузер не очистил кеш.
- OCR и языковые данные Tesseract могут потребовать интернет при первом использовании.
- Не проводился внешний penetration test или аудит серверной инфраструктуры. У проекта нет собственного сервера/авторизации.

## Перенос прогресса
Экспорт/импорт — ручной перенос JSON-файла. Это не автоматическая синхронизация и не облачное резервное копирование. Для автоматической синхронизации понадобится серверная часть или облачная база данных, авторизация и отдельная модель защиты данных.

## Важное замечание
Статическая проверка структуры уроков и экзаменационного банка подтверждает заполненность и согласованность данных, но не доказывает методическую безошибочность каждого правила. Для этого нужна отдельная экспертная вычитка по актуальным материалам ФИПИ.
