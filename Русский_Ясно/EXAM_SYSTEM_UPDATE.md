# Русский Ясно — независимая система экзаменов

## Что изменено

- Экзаменационные вопросы больше не берутся из `Lesson.task`, `Lesson.choices` или `Lesson.rationale`.
- Добавлен отдельный банк из 75 новых заданий: по три независимых задания для каждой из 25 учебных тем базового курса, ОГЭ и ЕГЭ.
- В заданиях используются новые предложения, слова, контексты и формулировки; проверяется применение правила.
- Варианты ответов и порядок вопросов перемешиваются на основе номера варианта.
- Тематический мини-экзамен выдаёт отдельные вопросы только по выбранному разделу.
- Полная базовая проверка включает 15 заданий по пяти базовым разделам.
- ОГЭ сохраняет структуру изложения, 11 тестовых заданий и сочинения.
- ЕГЭ сохраняет 26 тестовых заданий и сочинение.
- Повторная попытка переключает номер варианта, чтобы получить другую подборку и порядок ответов.
- Карточка базового курса добавлена в раздел экзаменов.
- Версия кеша Service Worker повышена до v9.

## Проверки

- В отдельном банке 75 записей; каждая из 25 тем содержит ровно 3 новых вопроса.
- TypeScript-синтаксис `App.tsx`, `examBank.ts` и `curriculum.ts` проверен транспиляцией TypeScript без синтаксических ошибок.
- `examBank.ts` отдельно прошёл строгую проверку TypeScript.
- Полная сборка Vite/React и ESLint не подтверждены: установка npm-зависимостей в среде выполнения превысила лимит времени. GitHub Actions должен выполнить `npm ci` и `npm run build` после загрузки проекта.

## Важное замечание об оценивании

Автоматический процент рассчитывается по тестовой части. Изложение и сочинение остаются письменными работами: сайт показывает критерии самопроверки, но не выставляет им автоматический балл. Поэтому итоговый процент не следует трактовать как официальный балл ФИПИ.
