# Русский Ясно v19 — проверка письменных работ

## Что изменено
- В результатах экзамена письменная работа теперь отображается отдельным блоком проверки.
- Показывается фактическое количество слов и минимальный ориентир из задания.
- Добавлен чек-лист по критериям конкретного задания (изложение/сочинение ОГЭ/ЕГЭ).
- Можно раскрыть и прочитать собственный ответ после завершения экзамена.
- Чек-лист интерактивный и показывает долю отмеченных критериев.
- При недостаточном объёме выводится предупреждение.
- Процент экзамена явно обозначен как результат автоматически проверяемой тестовой части; письменная часть не маскируется под автоматическую оценку.

## Ограничение
Это структурированная самопроверка, а не автоматическая экспертная оценка сочинения. Для выставления баллов по критериям ФИПИ требуется надёжная проверка содержания и аргументации человеком или специально валидированной системой. В этой версии письменная работа не влияет на автоматический процент тестовой части.

## Сохранность
Изменены только компонент результатов экзамена и стили письменного чек-листа. Курсы, уроки, экзаменационные банки, сохранение прогресса и журнал ошибок оставлены без намеренного изменения.
