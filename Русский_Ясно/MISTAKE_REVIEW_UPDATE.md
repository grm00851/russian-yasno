# Русский Ясно v18 — журнал ошибок

## Что добавлено
- После завершения независимого экзамена неверные и пропущенные ответы сохраняются в профиле ученика.
- Для каждой ошибки сохраняются маршрут, раздел банка заданий, формулировка, выбранный ответ, правильный ответ и объяснение.
- Повторное появление той же ошибки обновляет счётчик попыток, а не создаёт дубликат.
- В разделе «Прогресс» появился блок «Мои ошибки» с сохранёнными ошибками и возможностью убрать запись после повторения.
- Список ограничен 200 записями, отображаются последние 30; данные остаются в локальном хранилище браузера.
- Обновлена версия Service Worker, чтобы клиенты получили новые файлы.

## Ограничения
- Автоматически фиксируются ошибки в заданиях с выбором ответа из независимых экзаменов. Письменные работы не включаются: для них нет автоматической экспертной оценки.
- Удаление записи вручную означает, что ученик повторил правило; это не подтверждает освоение темы экзаменом.
- Данные остаются локальными и не синхронизируются между устройствами.

## Проверка
Архив проверен на целостность. Production build не прошёл в текущей среде: отсутствуют `vite/client` и типы Node в `node_modules`, поэтому `npm run build` остановился до сборки приложения. Не считать это успешной проверкой TypeScript/Vite.
