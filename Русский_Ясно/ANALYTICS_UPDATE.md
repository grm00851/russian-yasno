# Русский Ясно v20 — расширенная статистика

- История последних 100 завершённых экзаменов.
- Для каждой попытки сохраняются направление, тип, тема, процент тестовой части, число правильных ответов и дата.
- В разделе «Прогресс» показываются число экзаменов, средний и лучший результат.
- Добавлены сводки по базовому курсу, ОГЭ и ЕГЭ.
- Добавлена история последних десяти попыток.
- Показано распределение сохранённых ошибок по направлениям.
- Старые данные совместимы: отсутствие истории трактуется как пустой список.
- Письменные задания не включаются в процент автоматически проверяемой тестовой части.

Данные хранятся локально в браузере на этом устройстве; синхронизация между устройствами не реализована.
