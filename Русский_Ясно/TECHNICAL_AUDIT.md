# Русский Ясно — техническая редакция v14

## Что обновлено

1. **Хранение прогресса:** данные из `localStorage` проходят нормализацию; ограничены длины списков завершённых уроков и сданных разделов. Некорректный JSON не ломает запуск приложения.
2. **Полный базовый вариант:** генератор полного экзамена базового маршрута теперь возвращает задания из уроков базового курса вместо пустого списка.
3. **Service Worker:** версия кеша повышена до `v8`; при активации старые кеши с тем же префиксом удаляются. Навигационные запросы используют сеть с офлайн-резервом.
4. **Загрузка изображений:** профиль и OCR принимают только JPEG/PNG/WEBP и ограничивают размер файла; аватар уменьшается на клиенте перед сохранением.
5. **Политика контента:** в `index.html` сохранена CSP с запретом object/embed, ограничением источников скриптов, изображений, соединений и worker; задана политика referrer.
6. **Внешние ссылки:** внешние ссылки открываются с `rel="noreferrer"`.
7. **Сохранность данных:** прогресс остаётся локальным на устройстве; обновление не меняет ключ хранилища `russian-yasno-v2`.

## Проверки исходников

- Проверены React/TypeScript структура, конфигурация Vite, GitHub Pages workflow, PWA manifest и Service Worker.
- Поиск по исходникам не выявил `dangerouslySetInnerHTML`, `innerHTML`, `eval()` или `new Function()`.
- Обработчики JSON/localStorage обёрнуты в `try/catch`; загружаемые изображения валидируются по MIME и размеру.
- Проверено наличие отдельной обработки ошибок OCR и освобождения object URL для фото тренажёра.

## Сборка

Команды для локальной проверки после установки Node.js LTS:

```bash
npm ci
npm run lint
npm run build
npm run preview
```

GitHub Actions выполняет `npm ci` и `npm run build` перед публикацией GitHub Pages.

## Важно

Это клиентское приложение без собственного сервера и авторизации. Прогресс хранится только в браузере и не синхронизируется между устройствами. CSP, заданная через HTML meta, является дополнительной защитой, но не заменяет HTTP-заголовки безопасности хостинга. Автоматическая проверка текста объяснения — учебная эвристика, а не экспертная проверка сочинения или официальный балл ФИПИ.

## Версия v16 — обновление главной страницы и аналитики

- Главная страница получила блок общей учебной статистики: завершённые уроки, время с открытой активной вкладкой, начатые незавершённые уроки и последний результат пробника.
- Добавлена общая шкала освоения 100-урочной программы и отдельные индикаторы базового курса, ОГЭ и ЕГЭ.
- При открытии урока он записывается как начатый; после успешного завершения исчезает из списка незавершённых.
- Время обучения накапливается с шагом в минуту только пока вкладка видима. Данные сохраняются в существующем локальном профиле; старые профили автоматически получают значения по умолчанию.
- Обновлён Service Worker cache до v9, чтобы браузер запросил новую сборку.

Проверка: архив исходной версии распакован; статически проверены изменения и корректность архива. `npm run build` запускался, но TypeScript-сборка остановилась до проверки исходников из-за отсутствующих локальных типов `vite/client` и `node`. Полную сборку в этой среде подтвердить нельзя.
