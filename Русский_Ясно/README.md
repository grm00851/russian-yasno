# Русский Ясно

Учебная веб-платформа для подготовки к ОГЭ и ЕГЭ по русскому языку и для укрепления базовой грамотности. В ней 100 коротких занятий, тематические тренажёры и авторские пробные варианты. Урок засчитывается, когда ученик решает задачу и письменно объясняет правило своими словами.

## Учебный план

- 20 уроков по фундаменту: части речи, морфемика, формы слов, грамматическая основа и синтаксис.
- 40 уроков в маршруте ОГЭ: изложение, грамматические, орфографические и пунктуационные навыки, работа с текстом и сочинение.
- 40 уроков в маршруте ЕГЭ: нормы, орфография и пунктуация, синтаксис, выразительные средства, анализ текста и сочинение.

Каждый урок содержит цель, объяснение, пример, алгоритм, вопрос с разбором и обязательную попытку объяснить правило самому. Количество уроков само по себе не гарантирует оценку: важно пройти маршрут, возвращаться к ошибкам и выполнить письменные задания.

## Практика и экзамены

- Диктант можно прослушать русским синтезированным голосом, записать по памяти, затем открыть образец и сверить текст.
- Тренажёры орфографии и пунктуации предлагают новое задание и показывают расхождения с разбором правила.
- Фото тетради распознаётся в браузере через Tesseract.js. Снимок не отправляется на сервер; языковая модель скачивается при первом запуске OCR. Печатный текст распознаётся надёжнее рукописного, поэтому результат можно поправить перед проверкой.
- Три тренировочных варианта ОГЭ и три ЕГЭ включают таймер, задания с автопроверкой и письменную часть с критериями для самопроверки. ОГЭ ориентирован на опубликованный проект КИМ-2027: пояснение каждого примера обязательно. Отдельно можно пройти диагностику по теме.
- Варианты здесь авторские учебные материалы по структуре экзамена. Это не официальные КИМ, письменная часть не проверяется автоматически, а точные формулировки и критерии нужно сверять с документами ФИПИ нужного года.
- Имя, тема и прогресс хранятся локально в браузере.

По проекту ОГЭ-2027 структура и содержание КИМ не меняются; в сочинении обязательно пояснить каждый пример, критерий СК2 оценивается до 4 баллов, сочинение — до 8, вся работа — до 38. В проекте ЕГЭ-2027 изменений по русскому языку не заявлено. Это проекты для обсуждения: перед экзаменом сверь финальные документы и банк заданий ФИПИ: [ОГЭ](https://fipi.ru/oge/demoversii-specifikacii-kodifikatory) · [изменения ОГЭ-2027](https://doc.fipi.ru/oge/demoversii-specifikacii-kodifikatory/2027/Plan_izmeneniya_KIM_OGE_2027.pdf) · [ЕГЭ](https://fipi.ru/ege/demoversii-specifikacii-kodifikatory) · [изменения ЕГЭ-2027](https://doc.fipi.ru/ege/demoversii-specifikacii-kodifikatory/2027/Plan_izmeneniya_KIM_EGE_2027.pdf).

## Запуск

Нужны Node.js и npm. В папке проекта выполни:

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
npm run preview
```

## Технологии

React, TypeScript и Vite. Учебные материалы работают без API-ключей и внешнего сервера.

## Версия 13 — техническая оптимизация и аудит

- Ужесточена проверка сохранённых данных профиля и прогресса при чтении из `localStorage`.
- Добавлена обработка ошибок записи прогресса, включая переполнение хранилища.
- Для аватара и фотографий OCR ограничены типы файлов (JPG/PNG/WEBP) и размер (до 12 МБ); добавлена обработка ошибок чтения/декодирования изображения.
- Обновлена версия кэша Service Worker до v7, чтобы браузеры удалили устаревший кэш приложения.
- Добавлены базовые CSP-ограничения, политика referrer и улучшения доступности/адаптивности.
- OCR остаётся динамически загружаемым модулем, чтобы не включать его в основной стартовый пакет.

Проверки в этой среде: синтаксис TS/TSX проверен транспиляцией TypeScript; JSON package-lock проверен; Service Worker и скрипт генерации иконок прошли `node --check`; выполнены статические проверки на опасные DOM-вставки и незащищённое использование localStorage. Полная установка зависимостей, production build, ESLint, npm audit и браузерные тесты требуют успешного доступа к npm registry и запуска приложения в браузере.
