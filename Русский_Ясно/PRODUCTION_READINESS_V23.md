# Русский Ясно v23 — ежедневное использование

## Добавлено
- Service Worker v11: при установке кеширует HTML-оболочку и same-origin JS/CSS-ресурсы, обнаруженные в HTML; посещённые same-origin ресурсы также кешируются.
- Навигация при отсутствии сети возвращает ранее сохранённую страницу приложения.
- Добавлен индикатор состояния сети в настройках.
- Добавлен экспорт учебного профиля в JSON и импорт резервной копии на другом устройстве.
- Импорт проверяет формат и версию файла, ограничивает размер 5 МБ и требует подтверждение, поскольку заменяет локальный прогресс.
- Обновлены PWA-иконки и apple-touch-icon.
- Добавлены стили резервного копирования для узких экранов.

## Перенос между устройствами
1. На старом устройстве открой Настройки → Скачать резервную копию.
2. Передай JSON-файл себе через почту, облачное хранилище или кабель.
3. На новом устройстве открой сайт → Настройки → Импортировать копию.
4. Подтверди замену локальных данных.

Это ручной перенос, не автоматическая облачная синхронизация. Для автоматической синхронизации потребуется отдельный сервер/облачная база, учётные записи и правила защиты данных.

## Офлайн
- PWA нужно открыть онлайн хотя бы один раз, чтобы Service Worker установился и загрузил оболочку.
- Офлайн доступны закешированные HTML, JS, CSS и посещённые same-origin ресурсы.
- Внешние ссылки, OCR-движок/языковые данные при первом использовании и иные внешние ресурсы могут требовать сеть.
- Браузеры и iOS по-разному управляют сроком хранения кеша; офлайн-доступ не является гарантией при очистке данных браузера.

## Известные ограничения
- Прогресс продолжает храниться в localStorage на каждом устройстве отдельно до ручного импорта.
- Это не серверная синхронизация и не резервное копирование в облако автоматически.
- Для проверки production build и e2e-тестов нужны установленные npm-зависимости и запуск в браузерах/на устройствах.
